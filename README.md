## 核心能力

- **自主系统开发** — 独立完成需求分析、微服务架构与端到端交付：网关 + Java/Python 服务 + 模型服务的完整数据流，权限、异步任务与审计闭环（[寰航 · 系统架构](https://github.com/lsfjames/huanhang-smart-agriculture#3-系统架构)）。
- **问题解决** — 围绕真实约束做工程取舍：跨语言服务联调、检测/分类标签隔离、4GB 显存 OOM 续训、站外平台无开放接口时的「人工回填—管理员核验」方案（[寰航 · 工程问题与解决](https://github.com/lsfjames/huanhang-smart-agriculture#6-工程问题与解决)）。
- **AI Coding Agent 协作** — 以 Codex 开展 Vibe Coding：任务拆解 → 协作实现 → 排错重构 → 人工代码检查 → 测试验收（可追溯分支：[qihuang `codex/showcase`](https://github.com/lsfjames/qihuang-ai-showcase/tree/codex/showcase)）。
- **模型集成** — 视觉与语言模型接入业务：MobileNetV3 / YOLOv12n 推理落库、Ollama 本地 Qwen + OpenAI 兼容适配层、Neo4j 混合检索与引用核验拒答（[寰航 · 已验证成果](https://github.com/lsfjames/huanhang-smart-agriculture#5-已验证成果)）。
- **工程测试** — pytest / JUnit / Node 测试、E2E 与故障注入；岐黄后端与安全测试 48/48 通过，验证范围逐项标注（[岐黄 · 已验证成果](https://github.com/lsfjames/qihuang-ai-showcase#5-已验证成果)）。
